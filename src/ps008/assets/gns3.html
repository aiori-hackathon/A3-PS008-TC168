How do I connect my GNS3 lab?
  1. Create and start IOS routers named R1, R2 and R3 in GNS3.
  2. Configure reachable management IPs, SSH credentials and verified host keys.
  3. Copy the inventory example into .ps008/gns3-inventory.json, then replace project/node IDs and IPs.
  4. Install dependencies: python -m pip install -e ".[gns3]".
  5. Start this app with python -m ps008 --web --gns3-inventory .ps008/gns3-inventory.json.
  6. Use “Check GNS3 controller”, then “Capture router evidence”. See docs/GNS3_SETUP.md for the full walkthrough.
